Stage 2: Causal Graph Module (CGAD)

Transfer Entropy Adjacency Matrix (75x75) defining physical causality between sensors.

🕸️ Graph Convolutional Network (GCN): This matrix dictates how the CausalGraphModule mixes information. Row $i$ and Column $j$ indicates the causal strength from sensor $i$ to sensor $j$. The raw data is multiplied by this graph *before* entering the Encoder.

Stage 3: Association Discrepancy Tracker

Monitoring the KL Discrepancy between Prior Association (P) and Sequence Association (S)

💡 Min-Max Adversarial Discovery: The AD module computes self-attention across the 120 window length. We plot the symmetric KL divergence (discrepancy). In anomalous regions, the Sequence Association diverges strongly from the Prior Association, spiking the discrepancy.
